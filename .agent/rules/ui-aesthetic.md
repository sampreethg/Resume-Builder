# UI Craft & Anti-AI Template Rules

1. Anti-AI Tells to Ban:
   - NO generic landing-page gradients (e.g., violet-to-fuchsia blur blobs).
   - NO overused hero badges with subtle pulsing borders (e.g., "✨ Powered by AI").
   - NO generic 3-column card layouts where every card looks identical.
   - NO center-aligned everything; use asymmetric, intentional editorial alignments.

2. Typography & Color:
   - Use high-contrast, functional palettes: neutral base (`#0f172a` or `#111827`) with purposeful accents.
   - Use distinct type hierarchies: choose a solid geometric sans or modern serif for headers, and clean, legible grotesk for UI data.
   - Never highlight a single random word with italics or color inside a headline.

3. Form & Resume Specifics:
   - Clean, compact institutional form controls: clear labels, subtle borders (`border-neutral-200`), and visible focus outlines.
   - In A4 printable output, honor physical paper dimensions: strictly budget vertical space and prevent ugly page-break splits (`break-inside: avoid`).
